🔧 Firebase Sozlama
Firebase nima? Google'ning bepul ma'lumotlar bazasi. Telefon + noutbuk bir vaqtda ishlaganda natijalar real vaqtda ko'rinadi.

Qanday ulash:
1. firebase.google.com → Yangi loyiha
2. Realtime Database → Test rejimida boshlash
3. Loyiha sozlamalari → Web ilovasi → Config nusxalash
4. Quyidagi maydonlarni to'ldiring → Saqlash
📤 GitHub Pages orqali deployment
Bu faylni GitHub Pages'ga joylashtirish uchun:
1. git init → git add . → git commit
2. GitHub'da repo ochib push qiling
3. Settings → Pages → main branch → Save
4. URL: https://USERNAME.github.io/REPO

Barcha qurilmadan kirish uchun Firebase ham kerak!
